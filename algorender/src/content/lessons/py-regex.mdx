<Section step="hook" title="Text you can only describe">

Some text you can spell out, like a comma or the word `total`, and a string method finds it: `"total" in line`. Other
text you can only describe: every number in a message, or a code that is "two capital letters, then four digits". No
string method searches for "any digit". A **regular expression** is a short pattern for such text, and Python's `re`
module searches with one.

</Section>

<Section step="parts" title="The pieces you will see">

<Terms>
  <Term name="regular expression">A pattern for text, or regex for short: `\d+` means "one or more digits in a row".</Term>
  <Term name="match">A piece of the text that fits the pattern.</Term>
  <Term name="raw string">A string with an `r` before the quote, `r"\d+"`, in which every backslash stays exactly as typed.</Term>
  <Term name="quantifier">A mark after a piece of a pattern that says how many times it repeats: `+`, `*`, `?` or `{3}`.</Term>
</Terms>

`import re` loads Python's regex tools. Take it as a recipe for now: modules get a unit of their own later.

```python
import re

text = "Order 66 left on 12 May in 3 boxes"
m = re.search(r"\d+", text)        # the first fit, anywhere
print(m)                           # <re.Match object; span=(6, 8), match='66'>
print(m.group())                   # 66
print(re.findall(r"\d+", text))    # ['66', '12', '3']
print(re.sub(r"\d", "#", text))    # Order ## left on ## May in # boxes
print(re.fullmatch(r"\d+", text))  # None: the whole text isn't digits
```

A pattern is built from small pieces:

- Most characters match themselves: `cat` matches c, a and t in a row.
- `\d` is a digit, `\w` a letter, digit or underscore, `\s` a space, tab or new line, and `.` any one character but a
  new line.
- Square brackets match any one character inside them: `[aeiou]` is a vowel, `[A-Z]` a capital letter.
- After a piece, `+` means one or more, `*` zero or more, `?` zero or one, `{4}` exactly four and `{2,3}` two or three.
  Each repeats **only the piece just before it**: `ha+` matches `haaa`, not `haha`.
- Round brackets make a **group**, a part to take out on its own: `re.search(r"room (\d+)", "room 3B").group(1)` is
  `'3'`.

Why the `r`? In an ordinary string, a backslash starts a special character: `"\n"` is one character, a new line. The
`r` keeps every backslash as typed: `len(r"\n")` is 2. Without it, Python warns that `"\d"` is an invalid escape
sequence. Write every pattern as a raw string.

The four functions:

- `re.search(pattern, text)`: the first match anywhere, as a match object, or `None`. Its `.group()` is the text that
  fitted, so check first: `if m:` is true for a match and false for `None`.
- `re.fullmatch(pattern, text)`: a match only if the **whole** text fits: use it to check input.
- `re.findall(pattern, text)`: a list of every match, as strings. With one group, it lists just the groups.
- `re.sub(pattern, new, text)`: a **new** string with every match replaced. Strings never change in place.

A regex is harder to read than a method call. When the text is fixed, a string method is clearer: `"@" in email`,
`date.replace("-", "/")`. Reach for a regex when you can only describe the text by its shape.

</Section>

<KeyIdea>

**A pattern describes a shape of text.** `search` finds the first fit anywhere (or `None`), `fullmatch` checks the
whole text, `findall` lists every fit, and `sub` builds a new string. The text you search never changes.

<Section step="recap" title="What to remember">

- A regex describes a shape of text: `\d` a digit, `[A-Z]` a capital, `+` one or more.
- Write patterns as raw strings, `r"..."`, so backslashes reach `re`.
- `re.search` gives the first match anywhere, or `None`: check before calling `.group()`.
- `re.fullmatch` checks the whole string, `re.findall` lists every match, and `re.sub` builds a new string.
- A quantifier repeats only the piece just before it.
- When the text is fixed, a string method is clearer than a regex.

</Section>
