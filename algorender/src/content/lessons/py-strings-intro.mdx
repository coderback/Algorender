<Section step="hook" title="Programs that talk">

Most programs show people text: a greeting, a total, a warning. To build that text you need to join pieces together,
put numbers inside sentences, and pick out single letters. In Python, text is called a **string**, and a handful of
tools does nearly all of it.

</Section>

<Section step="parts" title="The pieces you will see">

<Terms>
  <Term name="string">Text in quotes: `"Ada"` or `'Ada'`. Either kind of quote works, as long as both ends match.</Term>
  <Term name="f-string">A string with an `f` before the quote. Anything in curly brackets inside it (a name, a sum, `len(word)`) is worked out, and its value put in its place.</Term>
  <Term name="index">A character's position, counting from 0. `word[0]` is the first character, and `word[-1]` the last.</Term>
</Terms>

```python
name = "Ada"
print("Hi " + name)     # Hi Ada: + joins strings, adding nothing between them
print("ha" * 3)         # hahaha: * repeats a string
print(len(name))        # 3: how many characters
print(name[0])          # A
print(f"{name} has {len(name)} letters") # Ada has 3 letters
```

`+` joins exactly what it is given: `"ice" + "cream"` is `"icecream"`, with no space. And it won't join text to a
number: `"Age: " + 30` stops with a `TypeError`, because Python won't guess whether you meant text or arithmetic.
Turn the number into text with `str(30)`, or put it in an f-string, which does that for you.

Indexes run from 0 to one less than the length, so the last character of a 3-letter word is `word[2]`, or simply
`word[-1]`. Asking for `word[3]` stops with an `IndexError`.

</Section>

<KeyIdea>

**`+` joins strings exactly as they are, and only strings.** Use an f-string to put numbers and names inside text,
`len` to count characters, and an index from 0 to pick one out.

</KeyIdea>

`+` joins strings exactly as they are: `"ice" + "cream"` is `"icecream"`. Commas in `print` add spaces, but `+`
never does. If you want a space, join one in: `first + " " + last`.

</Misconception>

<Section step="recap" title="What to remember">

- A string is text in matching quotes.
- `+` joins strings exactly as they are, and only strings; `*` repeats one.
- An f-string, `f"…{name}…"`, puts values inside text, numbers included.
- `len(s)` counts characters; `s[0]` is the first and `s[-1]` the last.

</Section>
