<Section step="hook" title="How does a network know which weight to blame?">

A neural network can have billions of weights. After it gets an answer wrong, training nudges every one of them in the
direction that would have made the error smaller. That needs the gradient of the loss with respect to every weight, and
computing them one at a time would take forever.

**Backpropagation** gets all of them in one backward sweep, for about the cost of running the network once. It is nothing
more than the chain rule from calculus, applied node by node on a graph. In this lesson you will watch it, then write it.

</Section>

<Section step="parts" title="The pieces you will see">

<Terms>
  <Term name="computation graph">A formula broken into small steps (add, multiply, tanh), each a box fed by its inputs.</Term>
  <Term name="forward pass">Computing every box's value from left to right.</Term>
  <Term name="local derivative">How much a box's output changes per unit change in one input, ignoring everything else: 1 for an addition, the other factor for a product, $1 - \tanh^2$ for tanh.</Term>
  <Term name="gradient">How much the final output changes per unit change in a box: what training needs.</Term>
</Terms>

</Section>

<Section step="see" title="Forward, then backward">

<Explore slug="chain-rule" settings={{ preset: 'simple' }} caption="Values flow left to right, then gradients flow right to left. Each step multiplies a local derivative by the gradient arriving from above." />

Each box only needs to know its own local derivative. The chain rule glues them together:

$$
\frac{\partial L}{\partial a} = \frac{\partial L}{\partial d}\cdot\frac{\partial d}{\partial e}\cdot\frac{\partial e}{\partial a}
$$

<KeyIdea>

**Gradient of an input = local derivative × gradient of the output it feeds.** If a value feeds several places, add up
what comes back from each. Walk the boxes in reverse order and every gradient falls out in one pass.

</KeyIdea>

</Section>

<Misconception
  id="gradient-set-once"
  title="A value's gradient is set once"
  probes={[
    {
      q: 'c = a + a with a = 3, and the gradient arriving at c is 1. What is the gradient of a?',
      choices: ['1', '2', '3', '6'],
      answer: 1,
      trap: 0,
      why: 'a is used twice, and each use sends back 1 × 1. The two add up to 2, just as d(2a)/da = 2.',
    },
    {
      q: 'b = a × a with a = 4, and ∂L/∂b = 1. What is ∂L/∂a?',
      choices: ['16', '4', '8', '1'],
      answer: 2,
      trap: 1,
      why: 'Each use of a sends back the other factor, 4. Both uses add up to 8, which matches d(a²)/da = 2a = 8.',
    },
  ]}
>

When a value is used in two places, its gradient is the **sum** of what both uses send back. Code that writes
`grad = …` instead of `grad += …` silently drops one path. Try the "a used twice" example above to see the two
contributions arrive one after the other.

</Misconception>

<Misconception
  id="gradient-passes-unchanged"
  title="The gradient passes back unchanged through every box"
  probes={[
    {
      q: 'y = 5 × x and the gradient arriving at y is 2. What is the gradient of x?',
      choices: ['2', '10', '5', '7'],
      answer: 1,
      trap: 0,
      why: 'The local derivative of 5 × x with respect to x is 5, so x gets 5 × 2 = 10.',
    },
    {
      q: 'h = tanh(n) with h = 0.6, and ∂L/∂h = 2. What is ∂L/∂n?',
      choices: ['2', '1.2', '0.64', '1.28'],
      answer: 3,
      trap: 0,
      why: 'tanh’s local derivative is 1 − h² = 1 − 0.36 = 0.64, and 0.64 × 2 = 1.28.',
    },
  ]}
>

Only an addition hands the gradient on unchanged, because its local derivative is 1. Every other box scales it: a
product by the other factor, tanh by $1 - \tanh^2$. Forget the local derivative and every gradient below that box is
wrong, usually by a lot.

</Misconception>

<Section step="recap" title="What to remember">

- A computation graph splits a formula into simple steps, each with an easy local derivative.
- Backward pass: output gradient 1, then each input's gradient += local derivative × upstream gradient, in reverse topological order.
- One backward pass gives the gradient for every input; this is how PyTorch and JAX train networks.
- Next: use these gradients for gradient descent on a real model, starting with linear regression.

</Section>
