<Section step="hook" title="Changing course mid-loop">

Looking for the first number that fits a rule? Once you've found it, there's no point checking the rest. Reading
words until someone types `stop`? You don't know how many there will be. Skipping the blank lines in some input? Two
small words handle all of these: `break` and `continue`.

</Section>

<Section step="parts" title="The pieces you will see">

<Terms>
  <Term name="break">Leaves the loop at once. Python carries on with the first line after the loop.</Term>
  <Term name="continue">Skips the rest of this turn and goes straight on to the next one.</Term>
  <Term name="loop else">An `else` lined up with the `for` or `while`. It runs once the loop has finished, but only if no `break` ended it.</Term>
</Terms>

`while True:` is a loop whose condition never fails, so the only way out is a `break`. It is the usual way to read
input until some signal:

```python
while True:
    word = input()
    if word == "stop":
        break           # leave the loop now
    if word == "":
        continue        # skip blank lines: back to the top for the next word
    print("got", word)
print("finished")
```

A loop's `else` answers the question "did the loop finish without a `break`?", which is just what a search needs:

```python
for d in range(2, n):
    if n % d == 0:
        print("found a divisor:", d)
        break
else:
    print("no divisor: prime")   # only when no break happened
```

The `else` lines up with the `for`, not with the `if`. That one level of indentation decides whether it runs once
after the loop or on every turn where the `if` is false.

</Section>

<KeyIdea>

**`break` leaves the loop; `continue` skips to the next turn.** A loop's `else` runs only when the loop ran to the end
without a `break`.

</KeyIdea>

<Section step="recap" title="What to remember">

- `break` leaves the loop at once; `continue` skips to the next turn.
- `while True:` with a `break` reads until a signal.
- A loop's `else` runs after the loop only if no `break` happened. Line it up with the `for` or `while`.

</Section>
