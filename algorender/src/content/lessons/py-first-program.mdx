<Section step="hook" title="A program is a list of instructions">

A program is a list of instructions written in a language the computer can carry out. Python is one of those
languages, and one of the easiest to read: most lines say what they do. This track starts from nothing at all. You
will write every program here, in your browser, and you can run any of them line by line to watch what each line
does.

Already know some Python? [Take the placement check](/learn/placement?area=languages) and skip what you know.

</Section>

<Section step="parts" title="The pieces you will see">

<Terms>
  <Term name="statement">One instruction, usually one line. Python carries them out one at a time, from the top of the file to the bottom.</Term>
  <Term name="print">Shows something on the screen. `print("Hi")` shows `Hi`, then moves to a new line.</Term>
  <Term name="string">Text in quotes, like `"Hi"` or `'Hi'`. Python shows it exactly as written.</Term>
  <Term name="comment">Anything after a `#` on a line, outside quotes. Python skips it: it is a note for people reading the code.</Term>
</Terms>

`print` can show numbers and sums as well as text. Give it several things, separated by commas, and it puts one space
between them:

```python
print("Hello!")          # Hello!
print(2 + 3)             # 5
print(4 * 2)             # 8: * multiplies
print("2 + 3 is", 2 + 3) # 2 + 3 is 5
print()                  # an empty line
```

The quotes make all the difference. Without them, `2 + 3` is a sum that Python works out before it prints. Inside
quotes, `"2 + 3"` is just five characters of text.

</Section>

<KeyIdea>

<Section step="recap" title="What to remember">

- A program is statements, carried out one at a time from the top down.
- `print(...)` writes one line. Several things, separated by commas, come out with spaces between them.
- Text goes in quotes and is shown as it is. A sum without quotes is worked out first.
- `#` starts a comment, which Python skips.

</Section>
