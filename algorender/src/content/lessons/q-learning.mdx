<Section step="hook" title="Learning without an answer key">

Every model so far learned from examples with the right answer attached: this point is class A, this house sold for
that much. Nobody can label every move of a game or every turn of a robot's wheel, though. What there is instead is a
score that arrives later: a win, a crash, a reward.

Reinforcement learning learns from that score alone. The agent acts, sees what happens, and slowly works out which
moves lead to reward, even when the reward comes many moves after the decision that earned it. This lesson builds the
classic method, Q-learning, on a few small grids.

</Section>

<Section step="parts" title="The pieces you will see">

<Terms>
  <Term name="state and action">Where the agent is (a cell of the grid) and what it can do there (move up, right, down or left).</Term>
  <Term name="reward">A number the world hands back after each move: +10 for the goal, −1 per step, −100 for the cliff.</Term>
  <Term name="discount γ">A reward $k$ moves away counts $\gamma^k$ times as much as one now. With $\gamma = 0.9$, ten points four moves away are worth $0.9^4 \cdot 10 \approx 6.6$ today.</Term>
  <Term name="Q-value">$Q(s, a)$: the total discounted reward the agent expects if it makes move $a$ in state $s$ and plays as well as it can afterwards.</Term>
  <Term name="policy">How the agent chooses moves. The greedy policy picks the move with the largest $Q(s, a)$; the arrows on the grid show it.</Term>
  <Term name="ε-greedy">Mostly greedy, but with chance $\varepsilon$ a random move instead, so the agent keeps trying things it doesn't yet rate.</Term>
</Terms>

</Section>

<Section step="see" title="Nothing, nothing, then a reward">

The agent starts with every Q-value at 0 and wanders. After every move it nudges one entry of its table towards a
*target*: the reward it just got, plus the discounted value of the best move from where it landed.

$$
Q(s, a) \leftarrow Q(s, a) + \alpha\,\big(\underbrace{r + \gamma \max_{a'} Q(s', a')}_{\text{target}} - Q(s, a)\big)
$$

<Explore slug="q-learning" settings={{ preset: 'maze', n: '100' }} caption="In the first episode, every target is 0 + γ·0 until the agent stumbles onto the +10. Then watch the value creep back towards the start, one cell per visit." />

Only the move that entered the goal learns anything in the first episode. On the next visit to the cell before it, the
target includes that cell's new value, so the reward spreads one step further back each time, shrinking by $\gamma$
per step. The wash fades with distance from the goal because of that discount.

<KeyIdea>

**Q-learning is dynamic programming learned from experience.** The true values satisfy the Bellman equation
$Q^*(s, a) = r + \gamma \max_{a'} Q^*(s', a')$: a move's value is its reward plus the value of the best next move. If
you know the rules of the world you can solve that table directly (value iteration fills it in sweep by sweep, like a
DP table). Q-learning fills in the same table without knowing the rules, one observed move at a time.

</KeyIdea>

</Section>

<Section step="see" title="Hugging the cliff edge">

Here every move costs 1 and the cliff costs 100. The fastest route runs right along the edge.

<Explore slug="q-learning" settings={{ preset: 'cliff', n: '100' }} caption="The moves chart falls towards the best route of 9 moves, but stays noisy: random exploring moves still tip the agent into the cliff now and then." />

The target uses $\max_{a'} Q(s', a')$, the value of acting *greedily* next, whatever the agent actually does next. So
Q-learning learns how good the edge is for an agent that never slips, even while its own ε-greedy wandering keeps
slipping. That is called learning **off-policy**. A method that learns the value of the policy it really follows (SARSA)
would pay for the slips and prefer a row further from the edge.

</Section>

<Section step="do" title="Near or far?">

From the start, a +1 is two moves away and a +10 is four. Which is better depends entirely on $\gamma$: the +1 is worth
$\gamma \cdot 1$ and the +10 is worth $\gamma^3 \cdot 10$. Work out both for $\gamma = 0.9$ and for $\gamma = 0.25$, then
run each and see which way the arrows from S end up pointing.

<Explore slug="q-learning" settings={{ preset: 'two-goals', n: '100' }} input />

Then use the input box to try:

- **The crossover:** at which $\gamma$ does the preference flip? (Solve $\gamma = 10\gamma^3$.)
- **No exploring:** set `epsilon = 0` on the near-or-far world. The first goal the agent stumbles onto is the one it
  keeps going back to, so the other one may never be found.
- **Too few episodes:** with `episodes = 10`, the arrows from S may still loop.

Q-learning's target always assumes the best next move, so it can learn the optimal values while acting almost at random:
the near-or-far world explores 80% of the time and still learns the right preference. What it can't do is learn about
places it never visits, which is why exploration is needed at all.

</Misconception>

  title="Q(s, a) is the reward for making that move"

      answer: 2,
      trap: 0,
      why: 'Q*(s, a) = r + γ · max Q(s′, ·) = −1 + 0.9 · 9 = −1 + 8.1 = 7.1. The reward of the move itself is only the first part.',
    },
    {
      q: 'Two moves both give r = 0 right now. One leads next to the goal, the other into a dead end. After learning, how do their Q-values compare?',
      choices: [
        'The move towards the goal has the higher Q-value',
        'They are equal, because both rewards are 0',
        'The dead-end move is higher, because it is safer',
        'Both stay at 0 for ever',
      ],
      answer: 0,
      trap: 1,
      why: 'A Q-value counts the discounted reward still to come, not just this move’s. The goal’s reward flows back into the move that leads towards it.',

A Q-value is not the reward of one move: it is that reward *plus* the discounted value of everything that can follow.
That is how a step costing −1 can have a high Q-value: it leads towards the +10. In the first episode almost every
reward is 0 or −1, yet the Q-values near the goal end up large.

</Misconception>

<Section step="recap" title="What to remember">

- The agent learns $Q(s, a)$, the discounted reward to expect from a move, and acts greedily on it, with chance $\varepsilon$ of exploring.
- Each update moves $Q(s, a)$ a fraction $\alpha$ towards $r + \gamma \max_{a'} Q(s', a')$; rewards spread backwards one step per visit.
- The fixed point is the Bellman equation, the same one dynamic programming solves when the rules are known.
- $\gamma$ trades near rewards against far ones; ε trades using what is known against finding out more.
- Next: replace the table with a neural network and the same update learns Atari games (DQN).

</Section>
