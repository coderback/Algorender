<Section step="hook" title="Once for each">

Many loops know exactly how many turns they need: once for each number from 1 to 10, once for each letter of a word.
A `while` loop can do that, but you have to set up the counter, test it and move it yourself, and forgetting one
of the three is the classic bug. A `for` loop does all three for you.

</Section>

<Section step="parts" title="The pieces you will see">

<Terms>
  <Term name="for">`for name in something:` runs its block once for each item, with `name` pointing at that item.</Term>
  <Term name="range">Makes a run of whole numbers: `range(5)` is 0, 1, 2, 3, 4.</Term>
  <Term name="end=">`print(x, end=" ")` finishes with a space instead of a new line, so the next print carries on the same line.</Term>
</Terms>

`range` stops **just before** the number you give it, so `range(5)` has five numbers, 0 to 4. Give it two numbers and
it starts at the first; give it a third and that is the step:

- `range(5)` gives 0 1 2 3 4
- `range(1, 5)` gives 1 2 3 4
- `range(1, 11)` gives 1 to 10
- `range(0, 10, 3)` gives 0 3 6 9
- `range(5, 0, -1)` counts down: 5 4 3 2 1

A range is for looping over: `for i in range(5):` runs its block with `i` as 0, then 1, and so on up to 4.

A `for` loop can walk through a string too, one character at a time:

```python
for ch in "hey":
    print(ch)     # h, then e, then y, each on its own line
```

</Section>

<KeyIdea>

**`for x in range(a, b):` runs once for each whole number from `a` up to, but not including, `b`.** A `for` loop can
also walk through the characters of a string.

`range` never includes its end. `range(5)` is the five numbers 0 to 4, and `range(1, 5)` is 1 to 4. To go up to `n`
itself, stop one later: `range(1, n + 1)`. A useful check: `range(a, b)` has `b - a` numbers in it.

</Misconception>

<Section step="recap" title="What to remember">

- `for x in range(n):` runs `n` times, with `x` from 0 to `n - 1`.
- `range(a, b)` stops just before `b`; `range(1, n + 1)` reaches `n`. A third number is the step.
- `for ch in text:` visits each character in turn.
- `print(..., end=" ")` keeps the next print on the same line.

</Section>
